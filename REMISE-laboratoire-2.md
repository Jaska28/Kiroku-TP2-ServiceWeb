## ▶️ Lancer le projet

Backend :

```bash
cd backend
npm install
npm run dev        # http://localhost:3000
```

Frontend :

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

Variables d'environnement à créer (non committées) : `DATABASE_URL`, `JWT_SECRET`.
